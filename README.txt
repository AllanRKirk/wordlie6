WORDLIE6 – README

Thank you for purchasing Wordlie6!

This is a standalone browser-based word puzzle game created by Allan Kirk.

HOW TO PLAY
-----------
1. Open wordlie6.html in any modern browser (Chrome, Edge, Firefox, Safari).
2. Use the on-screen keyboard to guess the 6-letter word.
3. Green = correct letter in correct place.
4. Gold = correct letter in wrong place.
5. Grey = not in the word.
6. Use ENTER to submit and DEL to delete.
7. Stats, streaks, hints, and celebrations are built in.
